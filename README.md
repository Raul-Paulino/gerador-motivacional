# 🌟 Gerador de Frases Motivacionais & Cartões Interativos

> Aplicação web moderna desenvolvida para consumir APIs públicas assíncronas, gerar citações inspiradoras traduzidas em tempo real e permitir o compartilhamento rápido de mensagens.

---

## 🚀 Sobre o Projeto
O **Gerador de Frases Motivacionais** é um projeto de estudo focado em **JavaScript Avançado (Consumo de APIs e Programação Assíncrona)**. A aplicação busca conselhos de uma API pública internacional, faz a tradução automática para o português via API de tradução e exibe o conteúdo em um cartão com fundo de gradiente dinâmico e opções de interatividade (copiar texto e envio direto via WhatsApp).

---

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica da aplicação.
- **CSS3:** Design responsivo, temas de gradiente dinâmico, efeitos de transição e sombras.
- **JavaScript (ES6+):** Manipulação do DOM, manipulação da Clipboard API e requisições assíncronas (`fetch` / `async` & `await`).
- **APIs Consumidas:**
  - [Advice Slip API](https://api.adviceslip.com/) - Fonte das frases e conselhos aleatórios.
  - [MyMemory Translation API](https://translated.net/) - Tradução em tempo real do inglês para o português.

---

## ✨ Funcionalidades
- 🔄 **Geração de Frases:** Busca de novos conselhos em tempo real.
- 🎨 **Cores Dinâmicas:** Alteração automática do gradiente de fundo a cada nova frase.
- 📋 **Copiar para Clipboard:** Permite copiar a frase formatada com um único clique.
- 📲 **Compartilhamento Direto:** Botão para enviar a mensagem diretamente no WhatsApp.
- 🌐 **Tradução Automática:** Integração com serviço de tradução sem dependência de bibliotecas pesadas.
